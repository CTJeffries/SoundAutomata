# Agentic Documentation

This directory contains AI-assisted analysis and summaries generated during the development of SoundAutomata.

## Files

- `GUI_ANALYSIS.md` - Comprehensive GUI widget inventory from Tkinter version
- `FINAL_SUMMARY.md` - Implementation summary after completing Textual port
- `FIXED_SUMMARY.md` - Issues fixed during migration to Textual
- `TEXTUAL_PORT_SUMMARY.md` - Technical details about the Textual port approach
- `TEXTUAL_README.md` - Usage documentation for Textual version
- `README_TEXTUAL.md` - Alternative Textual documentation (consolidated)
- `index.md` - Agentic docs index
- `MIGRATION_NOTES.md` - Python 2 to 3 migration notes
- `PORT_COMPLETE.md` - Port completion status
- `MIGRATION_SUMMARY.md` - Python 3 migration guide

## Purpose

These files were generated by AI assistants (Claude) to:
- Analyze the Tkinter codebase for porting to Textual
- Track implementation progress during migration
- Document technical decisions and trade-offs
- Provide testing guidance

## Usage

For development, use the files at top level:
- Core app: `App.py` (Textual GUI application)
- Modals: `ColorSelectModal.py`, `NotesSelectModal.py`
- Audio: `pyaudio_wrapper.py`, `paulstretch.py`, `SoundAutomata.py`

See the main [README.md](../README.md) for getting started.
