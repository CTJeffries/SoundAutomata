# SoundAutomata - Original Python 2 Version (Deprecated)

This directory contains the original Python 2 version of the Musical Cellular Automata Generator.

> **⚠️ Important:** Python 2 is end-of-life and no longer receives security updates. The Python 3 port (in the `python3/` directory) is actively maintained.

## Usage

Requirements:
- Python 2.x (2.7, 3.5-3.10 recommended)
- pygame

Run from this directory:

```bash
python AutomataApp.py
```

## Files in this Directory

- `AutomataApp.py` - Main GUI application
- `SoundAutomata.py` - Sound generation and cellular automata logic
- `paulstretch.py` - Audio stretching/synthesis utilities
- `README.md` - This file
